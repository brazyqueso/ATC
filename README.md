# ATC — Advanced Target Control

**Made by Pakun**

Hydra-class Kali menu. Not LFD. Install once, then `sudo ATC`.

Private repo. Clone it, then install.

```bash
git clone git@github.com:brazyqueso/ATC.git
cd ATC
sudo bash install.sh
sudo ATC
```

If you use GitHub CLI:

```bash
gh repo clone brazyqueso/ATC
cd ATC
sudo bash install.sh
sudo ATC
```

Puts the launcher in `/usr/bin/ATC` (Kali `sudo` ignores `/usr/local/bin`).
Also installs `atc` as a lowercase alias, a desktop entry, and a hydra icon.

Launch:

- terminal: `sudo ATC`
- Kali menu: **Applications → ATC**

```
github.com/brazyqueso
github.com/brazyqueso/ATC
```

Authorized lab / pentest use only.
